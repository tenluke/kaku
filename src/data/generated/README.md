# Generated character data: licences

These files are made by `npm run data` (see `scripts/data/`) from open sources. They are **not**
covered by the app's AGPL licence and nobody working on this app claims copyright over them.

- `strokes-*.json`: stroke paths from **KanjiVG**, © 2009–2026 Ulrich Apel,
  <https://kanjivg.tagaini.net/>, under CC BY-SA 3.0
  (<https://creativecommons.org/licenses/by-sa/3.0/>). Converted from KanjiVG's SVG files to JSON.
- `kanji.json`: meanings, readings, stroke counts and _Remembering the Kanji_
  frame numbers (6th edition) from **KANJIDIC2**, © James William Breen and
  the Electronic Dictionary Research and Development Group,
  <https://www.edrdg.org/wiki/index.php/KANJIDIC_Project>, under CC BY-SA 4.0 and the EDRDG licence
  (<https://www.edrdg.org/edrdg/licence.html>); JLPT levels from Jonathan Waller's JLPT lists
  (<https://www.tanos.co.uk/jlpt/>) via kanji-data (<https://github.com/davidluzgouveia/kanji-data>,
  MIT).
- `words.json`: words and their meanings from **JMdict**, © James William Breen and the Electronic
  Dictionary Research and Development Group,
  <https://www.edrdg.org/wiki/index.php/JMdict-EDICT_Dictionary_Project>, under CC BY-SA 4.0 and the
  EDRDG licence (<https://www.edrdg.org/edrdg/licence.html>). Only common words written in kana,
  each as `[kana, meaning, frequency rank, kanji spelling]`, with the meanings shortened.
- `sources.json`: which versions of the sources were used.

You may reuse these files under the same licences (share-alike). Details: `docs/CREDITS.md`.
